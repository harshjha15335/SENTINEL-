# Hackathon deployment checklist

## Complete in this workspace

- [x] Preserve recovered lineage and verify the pre-sprint Git bundle.
- [x] Exact migration-head readiness and fresh worker checks.
- [x] Supervisor, durable bridge and scoring jobs with stage-specific visibility.
- [x] Administrator operations page; global inbox aggregates explicitly scoped to the installation operator.
- [x] Isolated read-only judge scenario and guide with synthetic provenance.
- [x] Private database evidence and packet downloads.
- [x] Reject insecure hosted configuration and wildcard proxy trust.
- [x] Reviewed migration target and schema check before workers start.
- [x] Certificate-host proxy access checked with TLS verification.

## Required before describing the application as continuously hosted

- [ ] Independent bundle download and verification outside this workspace.
- [ ] Explicit Git publication authorization or another authorized source delivery path.
- [ ] Current official hosting quote, account access and cost approval.
- [ ] Continuously running container and separate persistent application database provisioned.
- [ ] Public HTTPS application URL tested; secure cookies and proxy trust verified on that host.
- [ ] API, pipeline and bridge readiness verified after host restart.
- [ ] Evidence/packet checksums survive the hosted restart.
- [ ] Scheduled backups, retention and a separate restore proven on the selected host.
- [ ] Judge viewer credentials supplied privately; no public administrator account.
- [ ] Official hackathon eligibility, submission requirements, deadline and video requirements checked from accessible rules.

## Separate provider milestones

- [ ] Sandbox OAuth authentication succeeds with securely corrected runtime binding.
- [ ] Real LLM investigation succeeds under bounded authorized test.
- [ ] Genuine PayPal event verification succeeds only after separately authorized provider testing.

No genuine payment should be initiated under this checklist without new authorization. Refund execution, dispute submission, Policy Lab, expanded analytics and Fraud Network Explorer remain later product work; their prerequisites are not silently waived by fixture success.
