# Skill-usage audit — rejected film and rebuild

The 16-skill installation was real. Installation did not mean all 16 were applied. Retained setup reports establish source/metadata review, but do not provide a complete tool-by-tool reading history for the old production. Therefore **historical SKILL.md reading is not independently proved for every row**. Implementation claims below are based on source files and rendered artifacts, not installed package names.

The rejected 170-second movie was inspected across its entire duration using 5-second frame sampling (rejected-full-contact.jpg), final-media metadata/decoder evidence, and the actual source assembly scripts. This is not claimed as human real-time listening.

## Root causes

1. The approved creative ambition was reduced to a wallet animation, repeated UI frames, flat text cards, and a constructed logo.
2. The native final assembly did not include most authored Remotion motion.
3. Gemini footage was appended late instead of placed beside the Gemini narration.
4. A technically valid encode was incorrectly treated as completion.
5. Voice and creative quality lacked a meaningful review gate.

## New reading evidence

This rebuild read local remotion-best-practices/create/markup/interactivity/render/captions/multimedia/studio/license skills and their applicable timeline, video-editing, 3D, layout and motion-blur references; the speech instructions; cloud runtime/desktop guidance; Supabase guidance for provenance handling; and React review guidance. No claim that unused Maps/SaaS/Upgrade skills were applied.
